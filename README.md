# mood 무드

기기 내 사진 색 분석과 립 제품 탐색 웹앱입니다. Node.js 24에서 외부 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm run build`로 JavaScript 문법을 확인합니다.

사진 업로드 → 사진에서 입술 중앙 클릭 → 컬러 분석. 카메라는 localhost 또는 HTTPS와 사용자 권한이 필요합니다. 사진은 서버로 전송하지 않습니다. 저장한 제품 ID는 브라우저 localStorage에 보관합니다.

현재 색 분석은 선택한 위치 주변 픽셀의 RGB 평균에 기반한 간단한 추정입니다. 자동 입술 추적, 전문 퍼스널 컬러 진단, 실시간 재고·가격 조회는 포함하지 않습니다. 제품 일러스트는 예시이며 실제 패키지 사진이 아닙니다. 제품 데이터와 가격은 참고용입니다.

추천은 20개 참고 색상 중 CIELAB 공간에서 밝기·채도·색조 차이를 비교해 가까운 4개를 표시합니다. 전체 보기와 톤 필터를 사용할 수 있습니다. 제품 HEX는 공식 측정값이 아닌 예시이며 색 유사도는 착용 적합 확률이 아닙니다. 색 분석 테스트: `npm test`.
